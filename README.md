# Bazis Furniture Generation

Профессиональный набор инструментов, интерактивных скриптов и полной базы знаний для автоматической параметрической генерации мебели, фасадов, ящиков и расстановки кастомной фурнитуры в САПР **Базис-Мебельщик (версии 2021, 2022, 2023, 2024)** на JavaScript (ES5 API).

---

## 🛠️ Состав основных инструментов

### 1. Интерактивная схема установки петель (`add_my_hinges.js` / `scripts/Схема установки петель (петля МОЯ).js`)
Работает как штатная **Схема крепежа** Базиса:
- **Интерактивный режим по клику**: при запуске скрипта достаточно кликнуть мышкой на стойку/боковину, затем на дверь/фасад — петли ставятся мгновенно. Скрипт работает в цикле (можно последовательно прокликать и навесить все двери гарнитура за несколько секунд).
- **Пакетный режим**: если стойки были предварительно выделены в 3D, скрипт автоматически навесит петли на все выделенные оси.
- **Кастомная фурнитура и точная присадка**: используется файл `петля МОЯ.f3d`:
  - На фасаде: глухая чашка `d35x13 мм` + 2 отверстия `3x4 мм` под крепежные саморезы;
  - На стойке: отверстия под крестообразную ответную планку `5x13 мм` (евро-отверстия).
- **Базирование по дну (70 мм)**: нижняя петля всегда позиционируется строго на расстоянии **`70 мм` от верхней пласти прилегающего дна**. Все петли шкафа выстраиваются в единую горизонтальную линию, исключаются коллизии с дном и стяжками Rafix.
- Верхняя петля: с отступом `100 мм` от верха двери, промежуточные петли распределяются с равным шагом.

### 2. Расчёт и генерация дверей (`add_doors_interactive.js` / `scripts/Установка дверей на стойки.js`)
- Выделите стойки в 3D и запустите скрипт — он рассчитает проёмы и создаст накладные фасады.
- **Осевое центрирование стыков**: зазор между смежными фасадами равен **`1.5 мм`** (`halfGap = 0.75 мм` от центральной оси промежуточной стойки).
- **Разноглубинность**: фасады автоматически привязываются к координате Z переднего торца конкретно своей секции (например, узкий пенал Z=330 и глубокий шкаф Z=600).
- **Фальш-планки**: декоративные узкие доборы у стен автоматически исключаются из расчёта дверей.
- Поддержка разной высоты: на всю высоту стоек, нижняя часть (тумба), верхняя часть (антресоль).

### 3. Генератор каркаса шкафа (`generate_cabinet.js` / `scripts/Генератор корпуса шкафа.js`)
- Построение полного параметрического корпуса: боковины, цоколь, дно, крышка, антресольная полка, средние стойки и полки.
- Автоматическая расстановка крепежа: евровинты 7×50, стяжки Rafix (Hafele), полкодержатели D5.
- Врезка эластичных выдвижных ящиков Blum (с боковыми планками под петли или прямо к боковинам).

## 🚀 Установка в Базис-Мебельщик (Запуск в 1 клик)

Чтобы запускать инструменты прямо из дерева скриптов Базиса без открытия редактора:

1. Скопируйте папку `scripts/` (или её содержимое) в каталог скриптов Базиса:  
   `C:\Users\<Ваш_Пользователь>\OneDrive\Документы\Bazis\Scripts\Генерация мебели\`
2. В интерфейсе Базис-Мебельщик откройте панель **«Скрипты»** — там появится папка **`Генерация мебели`**.
3. Дважды кликните по нужному скрипту для запуска.
