# Bazis Furniture Generation

Набор скриптов, утилит и базы знаний для параметрической автоматической генерации мебели (шкафы, ящики, полки, крепёж) в САПР **Базис-Мебельщик** (JavaScript API).

## Состав проекта

- **Скрипты генерации и тестов**:
  - `generate_cabinet.js` — генерация параметрического шкафа с секциями и ящиками.
  - `test_calibrated_drawer.js`, `test_3_drawers_no_planks.js` — калибровка и установка ящиков.
  - `test_euro_parametric.js`, `choose_and_mount_euro.js` — расстановка и врезка евровинтов / крепежа.
- **База знаний и документация**:
  - [МЕТОДИЧКА.md](МЕТОДИЧКА.md) — подробные правила, системы координат, вызовы методов API Базис-Мебельщик.
  - [BAZIS_KNOWLEDGE_BASE.md](BAZIS_KNOWLEDGE_BASE.md) — справочник по работе с объектами, блоками и фурнитурой.
  - Текстовые выдержки из официального руководства (`extracted_script_manual.txt`, `page*.txt`, `inffurniture_full.txt` и др.).
- **Фурнитура и пресеты**:
  - `fastener_presets.json` — конфигурация крепежа и фурнитуры.
  - `convert_json_cp1251.py` — утилита конвертации JSON в кодировку CP1251 (требуется для встроенного `system.readTextFile` в Базисе).
  - Папка `furn/` — 3D-модели крепежа и фурнитуры (`.f3d`).

## Быстрый старт

1. Ознакомьтесь с [МЕТОДИЧКА.md](МЕТОДИЧКА.md) для понимания системы координат и особенностей JS API Базис-Мебельщик.
2. Настройте пути к фурнитуре в `fastener_presets.json`.
3. При необходимости отредактируйте параметры и выполните `python convert_json_cp1251.py`.
4. Запустите скрипт `generate_cabinet.js` внутри Базис-Мебельщик.
