# Методичка: скрипт генерации шкафа в Базис-Мебельщик

Универсальные правила. Габариты корпуса в методичку не входят: ширина, высота, глубина, секции, ниши и число ящиков задаются параметрами скрипта. Крепёж и ящики берутся из `fastener_presets.json`.

Файлы крепежа ниже сделаны под плиту 16 мм.

---

## 1. Среда

- САПР: Базис-Мебельщик 2022.
- Язык скриптов: JavaScript.
- В строках скрипта каждый `\` пишется дважды: `'C:\\Users\\...'`.
- Вектор создаётся только через `NewVector(x, y, z)`. Вызов `Vector(x, y, z)` возвращает `undefined`.
- Конец скрипта: `Action.Commit()`, затем `ViewAll()`, затем `SetCamera(p3dIsometric)`.

Оси:

- **X** — ширина, слева направо.
- **Y** — высота, снизу вверх.
- **Z** — глубина, от задней кромки к фасаду.
- Ноль — левый задний нижний угол.

Толщина панели в `AddVertPanel` / `AddHorizPanel` / `AddFrontPanel` не передаётся: её берёт активный материал. Параметр `Thick` скрипт использует сам, чтобы считать стыки и проёмы.

## 4. Состав пресета

| Блок | Поля |
|---|---|
| `hardware.*` | `name`, `path`, `type` (`rafix`, `confirmat`, `shelf_holder`) |
| `schemes.VB`, `schemes.CONFIRMAT`, `schemes.SHELF_HOLDER` | `hardware` (ключ из `hardware`), `edgeOffset`, `count` |
| `drawers.*` | `path`, `usePlanks`, `plankCount`, `plankThick`, `plankHeight`, `guideLeftX`, `guideRightX`, `origBlockWidth` |
| `cabinet_connections` | имя стыка → имя схемы. Карту скрипт может задать свою |

Схему крепежа из интерфейса Базиса по имени вызвать нельзя. Схема в скрипте — это `count` вызовов `Mount` вдоль стыка. При двух точках они стоят на `edgeOffset` от начала и от конца интервала по Z:

```javascript
furn.Mount(panelWithFace, panelWithEdge, x, y, zStart + offset);
furn.Mount(panelWithFace, panelWithEdge, x, y, zEnd - offset);
```

## 5. Панели

Последний аргумент — плоскость, от которой панель растёт в плюс по своей оси. Деталь толщиной `Thick` занимает интервал `[pos, pos + Thick]`.

```javascript
AddVertPanel(z1, y1, z2, y2, x);   // вертикаль, плоскость X = x
AddHorizPanel(x1, z1, x2, z2, y);   // горизонталь, плоскость Y = y
AddFrontPanel(x1, y1, x2, y2, z);   // фронтальная, плоскость Z = z
panel.Name = '...';
```

Грани считаются из параметров корпуса:

- левая боковина: плоскость `X = 0`, внутренняя грань `X = Thick`;
- правая боковина: плоскость `X = TotalWidth - Thick`, наружная грань `X = TotalWidth`;
- горизонталь с низом `y`: середина плиты `y + Thick / 2`, верх `y + Thick`;
- фронтальная деталь у передней кромки: плоскость `Z = TotalDepth - Thick`.

Порядок построения: `NewModel()` → вертикали → цоколь → горизонтали → ящики → крепёж по карте стыков → `Action.Commit()`.

На вход скрипта:

- `TotalWidth`, `TotalHeight`, `TotalDepth`, `Thick`;
- цоколь: высота и отступ задней планки от задней кромки; передняя планка в плоскости `Z = TotalDepth - Thick`;
- вертикальные стойки: список позиций по X;
- горизонтали: у каждой низ плиты `Y` и участок по X;
- ниши ящиков: секция, чистая высота, ключ пресета ящика, число ящиков, зазор снизу, зазор между фасадами, утопление фасада по Z, высота фасада или авторасчёт;
- карта стыков: каждый стык ссылается на имя схемы из пресета.

## 6. Крепёж

`OpenFurniture(path)` возвращает объект с методом `Mount(panelWithFace, panelWithEdge, x, y, z)`.

**Евровинт.** `panelWithFace` — боковина, `panelWithEdge` — горизонталь, в торец которой входит винт. `X` — наружная пласть боковины: `0` слева, `TotalWidth` справа. `Y` — середина горизонтальной плиты, `y + Thick / 2`.

**Rafix.** Ставится на нижнюю пласть горизонтали. `Y` равен аргументу `y` из `AddHorizPanel`, не середине плиты. `X` — линия стыка: внутренняя грань боковины или плоскость перегородки.

**Полкодержатель.** Тот же вызов парой вдоль Z. `Y` — нижняя пласть полки, `X` — линия стыка со стойкой.

Одностороннее крепление перегородки — отдельные пары `Mount` к каждой горизонтали, с которой она стыкуется.

## 7. Ящики

`guideLeftX`, `guideRightX` и `origBlockWidth` читаются из пресета. Размах направляющих: `guideRightX - guideLeftX`.

```javascript
var wrapper = AddBlock('Контейнер_Ящик_' + i);
wrapper.Load(preset.path);
var dBlock = wrapper.Objects[0];
dBlock.ElasticResize(NewVector(targetBlockWidth, blockHeight, dBlock.GSize.z));
```

`ElasticResize` вызывается на вложенном блоке после `Load`, не на контейнере `AddBlock`. `IsElastic()` истинно, только если на блоке заданы плоскости эластичности. После сдвига вызывается `dBlock.Build()`.

Ширина блока:

- с планками: справа от ящика стоят `plankCount` вертикальных планок толщиной `plankThick` и высотой `plankHeight`. Целевой размах направляющих = чистый проём секции − `plankCount * plankThick`. Планки строятся отдельными `AddVertPanel` у правой стойки секции;
- без планок: планки не строятся, правая направляющая прижимается к правой стойке секции.

`targetBlockWidth = origBlockWidth + (целевой размах − исходный размах)`.

Позиция блока:

- `shiftX = внутренняя грань левой стойки секции − guideLeftX`;
- фасад ищется среди `dBlock.Objects` по имени `Фасад ящика` и условию `GSize.y > 50`;
- `shiftY = низ фасада в нише − facade.GabMin.y`;
- `shiftZ = TotalDepth − facadeIndent`.

По вертикали низ первого фасада = верх дна ниши + зазор снизу. Следующий фасад начинается через высоту фасада плюс зазор между фасадами. Если высота фасада считается сама:

`(чистая высота ниши − зазор снизу − зазор между фасадами × число ящиков) / число ящиков`

Зазор сверху в этой формуле равен межфасадному.
