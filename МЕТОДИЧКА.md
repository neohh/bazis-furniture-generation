## 1. Среда выполнения и правила синтаксиса

- **САПР**: Базис-Мебельщик (версии 2021, 2022, 2023, 2024).
- **Движок**: Встроенный интерпритатор JavaScript стандарта **ES5**.
- **ФАТАЛЬНЫЕ ОШИБКИ СИНТАКСИСА (Категорически запрещено)**:
  - ❌ `let`, `const` — приводят к синтаксической ошибке в Базисе. Всегда используйте **`var`**!
  - ❌ Стрелочные функции `() => {}` — запрещены. Используйте **`function(...) {}`**.
  - ❌ Шаблонные строки `` `Строка ${var}` `` — запрещены. Используйте конкатенацию: `'Строка ' + var`.
  - ❌ `Vector(x, y, z)` — функция возвращает `undefined`! Векторы создаются **ТОЛЬКО** через `NewVector(x, y, z)`.
  - ❌ Одинарные обратные слеши в путях: `'C:\Path'` сломает скрипт. Всегда экранируйте: `'C:\\Path\\To\\File.f3d'`.
- **Завершение транзакции**:
  - Обязательно в конце работы с геометрией вызывать:
    ```javascript
    Action.Commit();
    ```
    Без этого добавленные панели и блоки не сохранятся на чертеже/модели!
  - Обновление камеры и отображения:
    ```javascript
    ViewAll();
    SetCamera(p3dIsometric);
    ```

## 2. Система координат и глобальные габариты

### Оси координат Базиса:
- **X** — горизонталь (ширина шкафа, слева направо).
- **Y** — вертикаль (высота шкафа, снизу вверх).
- **Z** — глубина (от задней стенки к фасаду: `Z = 0` — задний торец, `Z = TotalDepth` — передний торец корпуса).
- Начало координат `(0, 0, 0)` — левый нижний задний угол габарита изделия.

### ⚠️ САМЫЙ ЧАСТЫЙ БАГ ИИ: `GSize` против `GabMin` / `GabMax`
- **`obj.GSize`** — это локальные размеры панели в её собственной системе координат!
  - Для вертикальной стойки (`AddVertPanel`) Базис часто задает `GSize.x` равным глубине (600 мм), а `GSize.z` толщине (16 мм).
  - Попытка отфильтровать стойки через `if (obj.GSize.x <= 25)` вернет 0 деталей!
- **СТРОГОЕ ПРАВИЛО**: определять геометрические размеры деталей **ТОЛЬКО** через глобальный Bounding Box:
  ```javascript
  var thickX  = obj.GabMax.x - obj.GabMin.x; // Толщина стойки по X (для ЛДСП 16 мм = 16.0)
  var heightY = obj.GabMax.y - obj.GabMin.y; // Высота детали по Y
  var depthZ  = obj.GabMax.z - obj.GabMin.z; // Глубина детали по Z
  ```

## 3. Методы построения панелей

Толщина материала в методы не передается — Базис берет её из активного материала (`ActiveMaterial.Thickness`). Скрипты рассчитывают проёмы исходя из стандартной плиты `Thick = 16 мм`.

Последний аргумент метода — координата базовой плоскости, от которой деталь нарастает в сторону положительных значений оси на величину толщины:

```javascript
// 1. Вертикальная стойка / перегородка (плоскость X = x, занимает [x, x + Thick])
// z1, y1 — задний нижний угол; z2, y2 — передний верхний угол
AddVertPanel(z1, y1, z2, y2, x);

// 2. Горизонтальная полка / дно / крышка (плоскость Y = y, занимает [y, y + Thick])
// x1, z1 — левый задний угол; x2, z2 — правый передний угол
AddHorizPanel(x1, z1, x2, z2, y);

// 3. Фронтальная деталь / фасад / цоколь (плоскость Z = z, занимает [z, z + Thick])
// x1, y1 — левый нижний угол; x2, y2 — правый верхний угол
AddFrontPanel(x1, y1, x2, y2, z);
```

### ⚠️ КРИТИЧЕСКОЕ ПРАВИЛО ДЛЯ `AddFrontPanel`:
`AddFrontPanel(x1, y1, x2, y2, z)` принимает координаты **ДВУХ ПРОТИВОПОЛОЖНЫХ УГЛОВ**:
- `x1, y1` — точка нижнего левого угла фасада;
- `x2, y2` — точка верхнего правого угла фасада (`x2 = x1 + width`, `y2 = y1 + height`);
- `z` — положение плоскости фасада по оси Z.

> [!WARNING]
> Передавать ширину и высоту вместо `x2, y2` **ЗАПРЕЩЕНО**! Например, `AddFrontPanel(0, 0, 400, 2000, 600)` построит фасад от X=0 до X=400. А `AddFrontPanel(100, 100, 400, 2000, 600)` построит фасад от X=100 до X=400 (ширина 300 мм, а не 400!).

## 5. Точные правила расчёта фасадов и дверей

### 1. Стандартные зазоры:
- `DoorGap = 1.5 мм` — зазор по периметру и между фасадами.
- `halfGap = DoorGap / 2 = 0.75 мм` — полузазор, откладываемый от геометрической оси стойки.

### 2. Расчёт по оси X (Ширина):
- **Крайняя левая стойка шкафа**:
  Фасад начинается с отступом `DoorGap` от наружного края:
  ```javascript
  x1 = postLeft.GabMin.x + DoorGap;
  ```
- **Промежуточные стойки (зелёная осевая линия)**:
  Стык двух смежных фасадов центрируется **СТРОГО ПО СЕРЕДИНЕ СТОЙКИ**:
  ```javascript
  var mid = (postMid.GabMin.x + postMid.GabMax.x) / 2;
  var leftDoorRightEdge = mid - halfGap; // Конец левого фасада
  var rightDoorLeftEdge = mid + halfGap; // Начало правого фасада
  ```
  *Проверка зазора*: `(mid + 0.75) - (mid - 0.75) = 1.5 мм` (идеальный зазор).
- **Крайняя правая стойка шкафа**:
  Фасад заканчивается с отступом `DoorGap` от наружного края стойки:
  ```javascript
  x2 = postRight.GabMax.x - DoorGap;
  ```
- **Фальш-планки, доборы и плашки у стены**:
  Декоративные узкие планки (глубиной менее 100-150 мм) в расчёт дверей **НЕ ВКЛЮЧАЮТСЯ**. Фасад перекрывает корпус до крайней несущей стойки!

### 3. Расчёт по оси Z (Глубина):
Накладной фасад ставится строго на передний торец стойки своей секции:
```javascript
var doorZ = post.GabMax.z;
```
> [!CAUTION]
> **Разноглубинные шкафы**: Если слева узкий пенал (глубина `Z = 330 мм`), а справа большой шкаф (глубина `Z = 600 мм`), двери пенала строятся на `Z = 330`, а двери шкафа — на `Z = 600`. Использовать единый Z запрещено!

### 4. Расчёт по оси Y (Высота):
- **Полноростовые фасады (от цоколя до крыши)**:
  - Низ: `doorY1 = socleFloorY + DoorGap` (например, `60 + 1.5 = 61.5 мм`);
  - Верх: `doorY2 = roofTopY - DoorGap`.
- **Раздельные фасады (тумба снизу / антресоль сверху)**:
  Фасады делятся по разделительной горизонтальной полке `shelf`:
  - Нижний фасад (тумба): `y1 = socleFloorY + DoorGap`, `y2 = shelf.GabMin.y - halfGap`;
  - Верхний фасад (антресоль): `y1 = shelf.GabMax.y + halfGap`, `y2 = roofTopY - DoorGap`.

## 6. Навеска петель: синтаксис `Mount`

Установка петли производится штатным методом Базиса:
```javascript
hingeObj.Mount(post, door, mountX, mountY, zFront);
```
- `post` — объект панели стойки (`Panel`).
- `door` — объект панели двери/фасада (`Panel`).
- `mountX` — X-координата базовой плоскости прилегания:
  - Если дверь справа от стойки: `mountX = post.GabMax.x`;
  - Если дверь слева от стойки: `mountX = post.GabMin.x`.
- `mountY` — высота установки петли:
  - **Нижняя петля**: строго **`70 мм` от верхней пласти прилегающего к стойке дна секции** (`bottomPanel.GabMax.y + 70 мм`) до центра петли! Это гарантирует, что петли всех секций будут на одной высоте по всему гарнитуру (даже если одни двери идут до пола, закрывая цоколь, а другие начинаются выше), а крестообразная планка не упрется в дно шкафа.
  - **Верхняя петля**: отступ `100 мм` от верхнего края двери (`door.GabMax.y - 100 мм`).
  - **Промежуточные петли**: делят расстояние между нижней и верхней петлями на равные отрезки:
    `stepY = (yEnd - yStart) / (count - 1);`
    `mountY = yStart + i * stepY;`
- `zFront` — передняя плоскость стойки `post.GabMax.z`.

> [!TIP]
> При использовании файла `петля МОЯ.f3d` метод `Mount()` автоматически создает в модели:
> 1. В фасаде: глухую чашку `d35x13 мм` и два отверстия `3x4 мм`;
> 2. В стойке: отверстия под крестообразную планку `5x13 мм`.

## 7. Монтаж крепежа корпуса (Евровинты, Rafix, Полкодержатели)

Базовый метод:
```javascript
furniture.Mount(panelWithFace, panelWithEdge, x, y, z);
```

| Тип крепежа | `panelWithFace` (Пласть) | `panelWithEdge` (Торец) | Координата X | Координата Y | Координаты Z |
|---|---|---|---|---|---|
| **Евровинт** (`confirmat`) | Боковина / стойка | Дно, крышка, полка | Наружная пласть боковины (`0` или `TotalWidth`) | Середина толщины плиты: `y + Thick / 2` | Парой с отступами: `zFront - 50` и `zBack + 50` |
| **Стяжка Rafix** (`vb`) | Полка / перегородка | Стойка / дно | Линия стыка: внутренняя пласть стойки | **Нижняя пласть** полки `y` (не середина!) | Парой с отступами: `zFront - 50` и `zBack + 50` |
| **Полкодержатель** (`shelf_holder`) | Стойка | Съёмная полка | Линия стыка со стойкой | Нижняя пласть полки `y` | Парой с отступами: `zFront - 50` и `zBack + 50` |

## 8. Выдвижные ящики и эластичные блоки (`ElasticResize`)

Ящик загружается из файла `.f3d` как единый эластичный блок:
```javascript
// 1. Создание контейнера и загрузка ящика
var wrapper = AddBlock('Контейнер_Ящик_' + i);
wrapper.Load(preset.path);
var dBlock = wrapper.Objects[0];

// 2. Растяжение по эластичности под ширину секции
// targetBlockWidth рассчитывается из чистой ширины проёма
dBlock.ElasticResize(NewVector(targetBlockWidth, blockHeight, dBlock.GSize.z));
dBlock.Build();

// 3. Позиционирование блока в нише
dBlock.Translate(NewVector(shiftX, shiftY, shiftZ));
```
- `shiftX`: рассчитывается от левой стойки секции с учётом базового смещения левой направляющей `guideLeftX` из пресета.
- `shiftY`: нижняя кромка фасада ящика в нише с учетом зазоров между ящиками.
- `shiftZ`: торец шкафа за вычетом отступа фасада ящика.

## 9. Алгоритм выборки деталей из 3D-сцены (`Selected`)

Когда пользователь выделяет детали в 3D мышкой, скрипт находит их через рекурсивный обход `Model`:

```javascript
var selectedPosts = [];

function scanScene(container) {
    if (!container) return;
    for (var i = 0; i < container.Count; i++) {
        var obj = container.Objects[i];
        if (obj.AsPanel) {
            var name = (obj.Name || '').toLowerCase();
            var thickX  = obj.GabMax.x - obj.GabMin.x;
            var heightY = obj.GabMax.y - obj.GabMin.y;
            var depthZ  = obj.GabMax.z - obj.GabMin.z;

            // Фильтр вертикальной несущей стойки:
            // 1. obj.Selected === true
            // 2. Толщина по X <= 35 мм (ЛДСП 16 мм)
            // 3. Высота > 200 мм
            // 4. Глубина > 150 мм (отсекает тонкие декоративные плашки)
            // 5. Не является фасадом
            if (obj.Selected && thickX <= 35 && heightY > 200 && depthZ > 150 && name.indexOf('фасад') === -1) {
                selectedPosts.push(obj);
            }
        }
        if (obj.Count && obj.Count > 0) scanScene(obj);
    }
}
scanScene(Model);
```

### Склейка составных стоек по оси X (Кластеризация):
Если стойка разрезана горизонтальными полками на несколько панелей (например, верхняя стойка антресоли и нижняя стойка тумбы), их X-координаты совпадают. Скрипт группирует панели с разницей X менее 15 мм:
`Math.abs(postA.minX - postB.minX) < 15 мм` $\to$ объединить в одну виртуальную вертикальную ось!

## 10. Эталонный скрипт: добавление дверей (`add_doors_interactive.js`)

Ниже приведён полный рабочий код скрипта интерактивного построения фасадов. Любая нейросеть может брать его за основу:

```javascript
// =========================================================================
// Скрипт добавления фасадов (дверей) по выделенным в 3D стойкам
// Базис-Мебельщик 2022 JS
// =========================================================================

var DoorGap = 1.5;        // Зазор между фасадами и по периметру (1.5 мм)
var halfGap = DoorGap / 2; // 0.75 мм — половина зазора на осевой стык

var selectedPanels = [];

function scanScene(container) {
    if (!container) return;
    for (var i = 0; i < container.Count; i++) {
        var obj = container.Objects[i];
        if (obj.AsPanel) {
            var name = (obj.Name || '').toLowerCase();
            var thickX  = obj.GabMax.x - obj.GabMin.x;
            var heightY = obj.GabMax.y - obj.GabMin.y;
            var depthZ  = obj.GabMax.z - obj.GabMin.z;

            if (obj.Selected && thickX <= 35 && heightY > 200 && depthZ > 150 && name.indexOf('фасад') === -1) {
                selectedPanels.push({
                    obj: obj,
                    name: obj.Name,
                    minX: obj.GabMin.x,
                    maxX: obj.GabMax.x,
                    minY: obj.GabMin.y,
                    maxY: obj.GabMax.y,
                    minZ: obj.GabMin.z,
                    maxZ: obj.GabMax.z
                });
            }
        }
        if (obj.Count && obj.Count > 0) scanScene(obj);
    }
}

scanScene(Model);

if (selectedPanels.length < 2) {
    alert('Сначала выделите в 3D как минимум 2 стойки секции шкафа!\nНайдено стоек: ' + selectedPanels.length);
} else {
    // Кластеризация стоек по оси X
    selectedPanels.sort(function(a, b) { return a.minX - b.minX; });

    var clusters = [];
    for (var i = 0; i < selectedPanels.length; i++) {
        var p = selectedPanels[i];
        if (clusters.length === 0) {
            clusters.push({ minX: p.minX, maxX: p.maxX, minY: p.minY, maxY: p.maxY, maxZ: p.maxZ });
        } else {
            var last = clusters[clusters.length - 1];
            if (Math.abs(p.minX - last.minX) < 15) {
                last.minX = Math.min(last.minX, p.minX);
                last.maxX = Math.max(last.maxX, p.maxX);
                last.minY = Math.min(last.minY, p.minY);
                last.maxY = Math.max(last.maxY, p.maxY);
                last.maxZ = Math.max(last.maxZ, p.maxZ);
            } else {
                clusters.push({ minX: p.minX, maxX: p.maxX, minY: p.minY, maxY: p.maxY, maxZ: p.maxZ });
            }
        }
    }

    clusters.sort(function(a, b) { return a.minX - b.minX; });
    var defaultDoors = clusters.length - 1;
    var countInput = prompt('Сколько дверей создать?\n(По умолчанию ' + defaultDoors + ' — по секциям шкафа):', defaultDoors.toString());
    var numDoors = parseInt(countInput, 10);
    if (isNaN(numDoors) || numDoors <= 0) numDoors = defaultDoors;

    var totalMinY = clusters[0].minY;
    var totalMaxY = clusters[0].maxY;
    for (var c = 1; c < clusters.length; c++) {
        totalMinY = Math.min(totalMinY, clusters[c].minY);
        totalMaxY = Math.max(totalMaxY, clusters[c].maxY);
    }

    var doorY1 = totalMinY + DoorGap;
    var doorY2 = totalMaxY - DoorGap;

    var heightChoice = prompt(
        'Высота дверей:\n' +
        '1 - По всей высоте стоек (' + Math.round(doorY1) + ' .. ' + Math.round(doorY2) + ' мм)\n' +
        '2 - Нижняя часть (тумба, нижняя половина)\n' +
        '3 - Верхняя часть (антресоль, верхняя половина)',
        '1'
    );

    if (heightChoice === '2') {
        doorY2 = totalMinY + (totalMaxY - totalMinY) / 2 - halfGap;
    } else if (heightChoice === '3') {
        doorY1 = totalMinY + (totalMaxY - totalMinY) / 2 + halfGap;
    }

    var createdDoors = [];

    // Вариант А: число дверей = числу секций между стойками (стыки строго по середине стоек)
    if (numDoors === (clusters.length - 1)) {
        for (var d = 0; d < numDoors; d++) {
            var leftAxis = clusters[d];
            var rightAxis = clusters[d + 1];

            var x1 = (d === 0) ? (leftAxis.minX + DoorGap) : ((leftAxis.minX + leftAxis.maxX) / 2 + halfGap);
            var x2 = (d === numDoors - 1) ? (rightAxis.maxX - DoorGap) : ((rightAxis.minX + rightAxis.maxX) / 2 - halfGap);
            var doorZ = Math.max(leftAxis.maxZ, rightAxis.maxZ);

            var panel = AddFrontPanel(x1, doorY1, x2, doorY2, doorZ);
            panel.Name = 'Фасад ' + (d + 1);
            createdDoors.push(panel);
        }
    } else {
        // Вариант Б: произвольное число дверей на весь выбранный пролёт
        var startX = clusters[0].minX + DoorGap;
        var endX = clusters[clusters.length - 1].maxX - DoorGap;
        var totalDoorSpan = (endX - startX) - (numDoors - 1) * DoorGap;
        var singleWidth = totalDoorSpan / numDoors;
        var doorZ = clusters[0].maxZ;

        for (var k = 0; k < numDoors; k++) {
            var kX1 = startX + k * (singleWidth + DoorGap);
            var kX2 = kX1 + singleWidth;
            var panelK = AddFrontPanel(kX1, doorY1, kX2, doorY2, doorZ);
            panelK.Name = 'Фасад ' + (k + 1);
            createdDoors.push(panelK);
        }
    }

    Action.Commit();
    alert('Успешно создано дверей: ' + createdDoors.length);
}
```

## 11. Эталонный скрипт: навеска петель (`add_my_hinges.js`)

Ниже приведён эталонный код навески настроенной петли пользователя с присадкой `d35x13 + 3x4` и `5x13`:

```javascript
// =========================================================================
// Скрипт-схема установки кастомных петель "петля МОЯ"
// Отверстия: d35x13 + 3x4 к фасаду, 5x13 к стойке
// Привязка: строго 70 мм от прилегающего дна до центра петли
// Режимы:
//   1. Интерактивная схема крепежа (клик по стойке -> клик по двери)
//   2. Пакетная установка на заранее выделенные стойки
// Базис-Мебельщик 2022 JS
// =========================================================================

var HINGE_BOTTOM_OFFSET = 70;  // Расстояние от верхней пласти прилегающего дна до центра нижней петли (мм)
var HINGE_TOP_OFFSET    = 100; // Отступ верхней петли от верхнего края двери (мм)

var HINGE_PATH_PRIMARY = 'C:\\Users\\maxim\\OneDrive\\Документы\\Bazis\\Фурнитура\\Blum петли\\Antarion\\Петли без заглушек и крестообр. планка\\Петля_CLIP top, CLIP без заглушек\\петля МОЯ.f3d';
var HINGE_PATH_LOCAL   = 'Z:\\Work\\генерация мебели\\furn\\петля_моя.f3d';

var hingeObj = null;
try {
    hingeObj = OpenFurniture(HINGE_PATH_PRIMARY);
} catch (e1) {
    try {
        hingeObj = OpenFurniture(HINGE_PATH_LOCAL);
    } catch (e2) {
        var userPath = system.askFileName('f3d;fr3d');
        if (userPath) hingeObj = OpenFurniture(userPath);
    }
}

if (!hingeObj) {
    alert('Не удалось открыть файл "петля МОЯ.f3d"!\nПроверьте путь к файлу фурнитуры.');
} else {
    var selectedPosts  = [];
    var allDoors       = [];
    var allHorizPanels = [];

    function scanScene(container) {
        if (!container) return;
        for (var i = 0; i < container.Count; i++) {
            var obj = container.Objects[i];
            if (obj.AsPanel) {
                var name = (obj.Name || '').toLowerCase();
                var thickX  = obj.GabMax.x - obj.GabMin.x;
                var thickY  = obj.GabMax.y - obj.GabMin.y;
                var heightY = obj.GabMax.y - obj.GabMin.y;
                var depthZ  = obj.GabMax.z - obj.GabMin.z;
                var widthX  = obj.GabMax.x - obj.GabMin.x;

                if (thickX <= 35 && heightY > 200 && depthZ > 80 && name.indexOf('фасад') === -1) {
                    if (obj.Selected) selectedPosts.push(obj);
                }
                if (name.indexOf('фасад') !== -1 || (depthZ <= 30 && widthX > 150)) {
                    allDoors.push(obj);
                }
                if (thickY <= 35 && widthX > 80 && depthZ > 80 && name.indexOf('фасад') === -1) {
                    allHorizPanels.push(obj);
                }
            }
            if (obj.Count && obj.Count > 0) scanScene(obj);
        }
    }

    scanScene(Model);

    function findAdjacentBottomPanel(post, targetDoor, side) {
        var pMinX = post.GabMin.x;
        var pMaxX = post.GabMax.x;
        var dMinX = targetDoor.GabMin.x;
        var dMaxX = targetDoor.GabMax.x;

        var bestPanel = null;
        var minFloorY = 999999;

        for (var h = 0; h < allHorizPanels.length; h++) {
            var hp = allHorizPanels[h];

            if (hpMinY < targetDoor.GabMin.y + (targetDoor.GabMax.y - targetDoor.GabMin.y) * 0.45) {

                    (Math.abs(hp.GabMax.x - pMinX) < 25 || (hp.GabMax.x >= pMinX && hp.GabMin.x < pMinX));
                var underPost = (hp.GabMin.x <= pMinX + 10 && hp.GabMax.x >= pMaxX - 10);

                    if (hpMinY < minFloorY) {
                        minFloorY = hpMinY;

    function mountHingesOnPair(post, door, side, count) {
        var pMinX = post.GabMin.x;
        var pMaxX = post.GabMax.x;
        var zFront = post.GabMax.z;

        var bottomPanel = findAdjacentBottomPanel(post, door, side);
        var yStart = bottomPanel ? (bottomPanel.GabMax.y + HINGE_BOTTOM_OFFSET) : (door.GabMin.y + HINGE_BOTTOM_OFFSET);
        var yEnd = door.GabMax.y - HINGE_TOP_OFFSET;

        if (yEnd <= yStart) yEnd = yStart + 100;

        var stepY = (yEnd - yStart) / (count - 1);

        var mountedCount = 0;
        for (var k = 0; k < count; k++) {
            var yPos = yStart + k * stepY;
            try {
                hingeObj.Mount(post, door, mountX, yPos, zFront);
                mountedCount++;

                system.log('Ошибка установки петли: ' + err);

    }

    var countInput = prompt('Количество петель на дверь (2, 3, 4, 5):', '4');
    var hingeCount = parseInt(countInput, 10);
    if (isNaN(hingeCount) || hingeCount < 2) hingeCount = 4;

    var totalMounted = 0;

    if (selectedPosts.length > 0) {

            '1'
        );

    if (!useInteractiveMode) {

        for (var p = 0; p < selectedPosts.length; p++) {
            var curPost = selectedPosts[p];
            var curMinX = curPost.GabMin.x;
            var curMaxX = curPost.GabMax.x;

            var dLeft = null;
            var dRight = null;
            var minLDist = 999999;
            var minRDist = 999999;

            for (var d = 0; d < allDoors.length; d++) {
                var cDoor = allDoors[d];
                if (cDoor.GabMax.y > curPost.GabMin.y && cDoor.GabMin.y < curPost.GabMax.y) {
                    var distR = Math.abs(cDoor.GabMin.x - curMaxX);
                    if (distR < 35 && distR < minRDist) {
                        minRDist = distR;
                        dRight = cDoor;
                    }
                    var distL = Math.abs(cDoor.GabMax.x - curMinX);
                    if (distL < 35 && distL < minLDist) {
                        minLDist = distL;
                        dLeft = cDoor;
                    }
                }
            }

            var targets = [];
            if (dLeft && dRight) {
                var sChoice = prompt(
                    'Стойка: ' + (curPost.Name || 'Перегородка') + '\nДвери найдены с обеих сторон!\nКуда крепить петли?\n1 - На правую дверь\n2 - На левую дверь\n3 - На обе двери',
                    '1'
                );
                if (sChoice === '1') targets.push({ door: dRight, side: 'right' });
                else if (sChoice === '2') targets.push({ door: dLeft, side: 'left' });
                else if (sChoice === '3') {
                    targets.push({ door: dRight, side: 'right' });
                    targets.push({ door: dLeft, side: 'left' });
                }
            } else if (dRight) {
                targets.push({ door: dRight, side: 'right' });
            } else if (dLeft) {
                targets.push({ door: dLeft, side: 'left' });
            }

            for (var t = 0; t < targets.length; t++) {
                totalMounted += mountHingesOnPair(curPost, targets[t].door, targets[t].side, hingeCount);
            }
        }
        Action.Commit();
        alert('Готово! Установлено петель: ' + totalMounted + '\nБаза: 70 мм от прилегающего дна.');

    } else {
        // Режим 2: интерактивная схема крепежа
        alert('СХЕМА КРЕПЕЖА ПЕТЕЛЬ:\n1. Кликните стойку (боковину);\n2. Кликните фасад (дверь);\nКоманда работает в цикле. Для выхода нажмите Esc.');

        while (true) {
            var pickedPost = null;
            try {
                pickedPost = GetPanel('1/2: Укажите стойку/боковину (или Esc для выхода)');
            } catch (ePost) { pickedPost = null; }
            if (!pickedPost) break;

            var pickedDoor = null;
            try {
                pickedDoor = GetPanel('2/2: Укажите дверь (фасад) для этой стойки (или Esc)');
            } catch (eDoor) { pickedDoor = null; }
            if (!pickedDoor) break;

            var postCenter = (pickedPost.GabMin.x + pickedPost.GabMax.x) / 2;
            var doorCenter = (pickedDoor.GabMin.x + pickedDoor.GabMax.x) / 2;
            var pickedSide = (doorCenter > postCenter) ? 'right' : 'left';

            totalMounted += mountHingesOnPair(pickedPost, pickedDoor, pickedSide, hingeCount);
            Action.Commit();
        }

        if (totalMounted > 0) {
            alert('Схема крепежа завершена!\nУстановлено петель: ' + totalMounted + '\nПривязка: 70 мм от прилегающего дна.');
        }
    }
}
```
